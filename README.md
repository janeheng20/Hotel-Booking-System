# Hotel Booking System

## Project Overview
Welcome to **Five Ninja Hotel**, a simple hotel booking system built in C++ that allows users to manage room bookings, check-in, check-out, and bill generation for various room types (Deluxe, Normal, and Presidential).

## Features
- **Room Availability**: Check available rooms for each room type.
- **Booking**: Book a room by providing customer details and stay duration.
- **Check-in & Check-out**: Manage check-in and check-out processes for customers.
- **Bill Generation**: Generate and display bills based on room type and the number of days stayed.

## How to Use
1. **Start the Program**:
   - Upon starting, you will be presented with a menu to choose from different options (Booking, Check-in, Check-out, Bill, or View Room Availability).

2. **Room Booking**:
   - Choose a room type (Deluxe, Normal, or Presidential).
   - Enter your customer ID, name, phone number, and the number of days you want to stay.

3. **Check-in/Check-out**:
   - Provide your customer ID to check-in or check-out.

4. **Bill Generation**:
   - To view the bill, provide the customer ID to fetch the details and display the total cost.
